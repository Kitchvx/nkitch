# nkitch.com Website

Live Site: [https://nkitch.com](https://nkitch.com)

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Nginx via VPS

## Run it locally

### Pre-reqs

- Git
- Node -v 24
- npm -v 12.2 (or older)

I like fnm to manage node.

### Clone it

Windows!

```ps
git clone https://github.com/Kitchvx/nkitch.git \Your\Git\Dir
```
